Install in a minute

Windows 10 or 11, 64-bit.

  1. Download VideoDownloader.exe and put it in its own folder, for example Documents\Video Downloader. The app keeps its settings next to the file.
  2. Double-click it. If Windows shows "Windows protected your PC", click More info → Run anyway. That box appears because the app isn't code-signed yet.
  3. Let it set up its tools. On first launch it offers to install yt-dlp and FFmpeg (free, open-source) for you. Then paste a link and press Enter.

To check your download, compare its SHA-256 with the one on the release page. In PowerShell: Get-FileHash .\VideoDownloader.exe -Algorithm SHA256

Questions

Short answers to the common ones.

Which websites work?

Every site the open-source yt-dlp project supports (over 1,700), plus direct video files and .m3u8 / .mpd streaming links. Sites change often; if one stops working, click Update downloader in the app.

Can it download Netflix, Prime Video, Hotstar or Spotify?

No. Those use DRM copy protection, and the app doesn't try to get around it. Screen recordings of DRM players show black for the same reason.

Does it work on Mac or Linux?

No, Windows 10 and 11 (64-bit) only.

Why does Windows warn me when I open it?

New apps without a paid code-signing certificate get a SmartScreen warning. Download only from this site or the GitHub Releases page, and compare the SHA-256 if you want to be sure.

Does the app collect my data?

No analytics, no tracking, no account. It only sends something when you choose to use the Support form. Details in the privacy policy.

How many PCs can I use Pro on?

One licence key works on up to 2 PCs. If you change PCs, contact support with your key and support ID.
